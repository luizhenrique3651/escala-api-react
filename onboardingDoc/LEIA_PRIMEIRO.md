## 🎓 Se Você é um Dev Java

### Seu Background Ajuda!
- ✅ Entende requisições HTTP
- ✅ Conhece autenticação/JWT
- ✅ Sabe o que é cache
- ✅ Programação orientada a eventos
- ✅ Type safety (TypeScript == Spring)

### Você vai achar fácil se...
- Souber básico de JavaScript
- Estiver familiarizado com REST APIs
- Entender callbacks/promises

### Não se assuste com...
- JSX (é HTML dentro de JavaScript)
- Hooks (é só lógica em funções)
- Reactive updates (como Spring reactive)
